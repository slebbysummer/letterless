Mission briefing
  1. Each round, every agent gets one turn as the clue-giver: 60 seconds to get as many words cracked as possible.
  2. Describe each secret word without using any of its letters. Banned letters are locked.
  3. Words get harder as you go: each one bans more letters than the last.
  4. Everyone else guesses as often as they like. Wrong guesses are visible to all.
  5. The first agent to crack a word wins a point, and so does the clue-giver. Then the next word appears.
  6. Stuck? You get one pass per turn.
Tip: Watch which letters the clue-giver avoids. They might be in the word.
